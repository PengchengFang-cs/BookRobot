# FPC 当前状态

更新时间：2026-08-18

## 当前阶段

当前处于书本感知真机验证与底盘精确转向验证阶段。书本感知链已经在真实场景中首次返回 mask 和 `base_link` 吸取点，但这次依赖临时运行环境和扩大后的关节历史缓存；正式入口尚需修复后复测。在该验证完成前，不接入导航或吸取动作。

## 已完成且仍有效

- FruitTest 已复制到受控的 `fpc` 工作区；当前开发使用该可废弃副本，不修改机器人上的其他旧工程。
- 书本感知已经替换原有 HSV 水果识别路径。5090 mask client、Wanda 本地 RGB-D 几何、同步帧选择、以采集时刻为基准的 deadline、仅感知入口、测试及 review fixes 均已进入 `main`。详细设计与实施记录见[书本感知替换设计](superpowers/specs/2026-08-17-fruittest-book-perception-design.md)和[实施计划](superpowers/plans/2026-08-17-fruittest-book-perception.md)。
- 部署路径是从 5090 的工作区经 SSH 更新 Wanda，不由 Wanda 从 GitHub pull。
- 底盘释放后，用户已在真机上确认前进、后退和升降可用。
- 用户确认此前手柄不能旋转是操作方式错误；改用正确操作后已能旋转并把机器人移动到测试位置。
- 真实场景临时联调已跑通“Wanda RGB-D → 5090 mask → Wanda 本地几何”。头部保持标定低头姿态 `joint_head1=0.24997 rad` 时，桌上 5 本书全部进入画面。FruitTest 现按 `0.25` 阈值过滤并返回最多 5 本几何有效书；2026-08-18 真机复测返回 5 本，置信度为 `0.538–0.565`，调试图分别覆盖五本书。

## 下一步

1. 让 perception-only 入口直接加载机器人已有的 gRPC sysroot、证书/protobuf路径和当前服务身份，并把关节历史缓存扩大到能够覆盖实测图像延迟。
2. 对同一次 capture 保存 mask 调试叠加图和 perception-only JSON：肉眼确认 mask 覆盖目标书本并确认 JSON 的 `frame_id` 为 `base_link`。调试叠加图或配套几何记录必须包含长短轴、机器人视角近端、右边缘和吸取点投影，并记录由这些量推导的 long/right inset，用于分别核对 `0.13 m`/`0.10 m` 固定偏移。当前 perception-only JSON 报告 `ok`、`frame_id` 和 `suction_point_m`，不含上述几何字段；这些字段是验证阶段需要补充的诊断输出，不视为当前已有能力。
3. 只有上述视觉与几何验证通过后，才规划接入导航或吸取动作。
