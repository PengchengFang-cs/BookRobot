# Stage 1 当前唯一 Pipeline

更新时间：2026-08-20

本文是 Stage 1 运行顺序的权威记录。旧地图导航、`0.48 m` 水果距离、
`0.8 m` 小推车中心距离以及断点续跑均不属于当前 Pipeline。

## 1. 书桌抓书

1. 粗导航到书桌前。
2. 拍摄 RGB-D，由 5090 输出书本 mask，Wanda 用本机深度计算 13/10 抓取点。
3. 根据 Pick DataReplay 第 0 帧参考点重复微调底盘前后和左右，直到对齐。
4. 恢复 Pick DataReplay 第 0 帧的全身姿态。
5. 原样执行 Pick DataReplay；D01 按已确定的回放帧启动。

## 2. 从书桌转移到小推车

1. Pick 完成后保持吸盘开启，底盘后退 `0.20 m`。
2. 从面向书桌开始左转 `90°`；每转 `15°` 拍一帧，共六帧，旋转结束后由
   5090 顺序处理并选择小推车检测结果。
3. 此时机器人已经左转 `90°`。用整车中心点在原书桌坐标系中的左右分量，
   估算当前朝向上的直行距离并前进到小推车附近。
4. 右转 `90°`，恢复为正面朝向小推车。
5. 前进 `0.20 m`，抵消步骤 1 的固定后退。到这里粗导航结束。

整车 mask 中央的 `cart navigation target` 只服务于步骤 3 的长距离粗估。
它不是底盘最终目标，也不用于小推车前的精确前后距离。

## 3. 小推车精定位与放书

1. 正面重新拍摄 RGB-D，检测整车并在 mask 内用深度提取最高可用托板。
2. 从托板真实左边缘计算五个横向槽位中心：`17/24/31/38/45 cm`。
   无论托板来自整车 mask 的深度分层还是单独的 `cart_platform` mask，槽位
   编号和距离都完全相同，不再使用备用算法的从右到左均分。
3. 从 Place 2.4 DataReplay 第 0 帧提取同一托板的前沿、左右轴和方向，作为
   回放起始几何参考。
4. 实时托板前沿与第 0 帧前沿决定前后修正；当前书号的槽位中心与录制释放
   位置的横向关系决定左右修正；托板边缘方向决定 yaw 修正。
5. 修正后重新检测并计算，允许多轮精调；不使用整车中心 `0.8 m` 规则。
6. 恢复 Place 2.4 第 0 帧全身姿态，其中升降柱为 `0.20 m`，保持吸盘开启。
7. 原样执行 388 帧 Place 2.4，在 frame 190 关闭吸盘且不吹气释放。

## 4. 放书后返回书桌

1. 底盘保持不动，头部向机器人右侧依次扫描 `30/45/60/75°`，调用书本视觉，
   从所有成功帧中选择坐标系中最右侧的书。
2. 后退 `0.20 m`，给右转留出空间。
3. 右转 `90°`，沿直线驶向书桌；直行距离由所选书的左右坐标与下一轮抓书
   粗参考横向位置计算。
4. 左转 `90°` 恢复正面朝向书桌，再前进 `0.20 m` 抵消步骤 2 的后退。
5. 进入下一轮书本检测和 DataReplay 第 0 帧精定位。扫描角度只用于找书桌，
   不会让底盘在扫描期间转动。

## 5. 当前实现边界

- 书本检测、Pick 对位与 Pick 回放已经存在。
- 后退、六帧扫描、直行到车旁、右转和前进 `0.20 m` 的粗导航已经存在。
- 小推车托板深度提取和五个槽位点已经存在；实测托板宽度约 `75.65 cm`，
  与现场手工测量 `75 cm` 一致。
- Place 2.4 第 0 帧托板参考已经从新录像标定：升降柱约 `0.20 m`、托板宽
  `0.7665 m`、第一槽距左边缘 `0.17 m`。
- 每轮精定位使用第一张检测成功的图立即计算，不为同一轮等待三张图；检测失败
  才继续拍摄。最多执行三次“单图→完整 XY+yaw 修正”，最终再用一张单图确认。
  同一张图的 yaw 不再独占一轮；`cart_platform` mask 的实测方向波动约 2°，
  当前 yaw 验收范围为 `±3°`。
- `--book-place` 从当前推车粗定位位置开始精定位和放书；
  `--book-pick-place` 连续完成一本书的 Pick→Place；`--stage1-loop` 串联五本书
  并在每次 Place 后按上述路线返回书桌。
- 这些入口已实现并完成离线测试；本轮没有发送任何真机运动命令。
