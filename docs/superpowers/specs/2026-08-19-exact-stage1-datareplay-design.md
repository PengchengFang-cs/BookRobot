# Stage 1 完整 DataReplay 抓书修复设计

日期：2026-08-19

状态：用户已确认修订设计；本文件只定义实现合同，不代表已部署或已进行真机测试。

## 1. 目标

Stage 1 Pick 必须完整复现 `S1_TABLE_PICK_BOOK` 资产的动作语义。回放前先恢复录制第 0 帧的机器人—书本相对位置和机器人关节姿态；回放时发送资产中存在的底盘、双臂、头部、升降柱动作，并按录制时序执行右 D01 吸附。

本次修复不修改原始 HDF5，不修改 `/home/unix_ai/WHRC`、`/home/unix_ai/DataCollector` 或 `/home/unix_ai/navnav_final`。实现与测试只写入 `/home/cvailab/fpc`，部署目标仍为 `/home/unix_ai/fpc`。

## 2. 已确认根因

当前 Pick HDF5 的 `target_base_vel` 在 178 帧中非零：录制前半段包含前进，吸附附近包含后退。旧 V3 配置却设置 `allow_base_motion=false`，当前 FPC 又要求该值为 `false`，导致 `RobotReplayer(skip_base=True)` 主动丢弃底盘动作，只回放双臂、头部、升降柱和 D01。

当前代码还存在以下已确认错误：

- 最终 X/Y 验收失败后仍无条件启动 Pick 回放。
- 回放前只预置升降柱，不恢复或验收双臂、头部和底盘朝向。
- 默认粗定位先把书本点移动到 `0.48 m`，随后又移动到 DataReplay 第 0 帧参考 `0.935579 m`，形成错误的靠近—退回往返。
- D01 frame 300 事件在 frame 300 动作发布前执行。
- 书本重关联没有最大距离和几何一致性拒绝条件。
- `--check` 可与真实运动参数组合，并因分支顺序失去“不运动”语义。

## 3. 用户确认的运行语义

### 3.1 默认流程

默认不执行粗定位。一次 Pick 的固定顺序为：

```text
检测目标书
→ 恢复 DataReplay 第 0 帧底盘—书本相对位置与底盘朝向
→ 最终视觉复测并验收同一本书
→ 平滑恢复双臂、头部和升降柱到 HDF5 第 0 帧状态
→ 确认 D01 处于 Pick 起始状态
→ 从 frame 0 开始完整播放 607 帧
→ 每帧发送资产中存在且合同允许的底盘、双臂、头部、升降柱动作
→ 先发布 frame 300 动作，再执行 right_suction_start
→ 继续播放剩余帧并确认 holding
```

底盘位置、底盘朝向和机器人关节姿态缺一不可。不能把回放的 frame 0 命令当成“复位动作”直接跳变过去。

### 3.2 可选粗定位

粗定位是显式可选项，默认关闭。它只用于机器人距离目标很远、尚未进入精确对位工作范围的情况。

粗定位不得再把 `0.48 m` 当作书本 Pick 目标，不得执行 `0.48 → 0.935579 m` 往返。粗定位完成后必须重新拍摄，再按第 0 帧合同执行精确位置和朝向恢复。

CLI 提供清楚命名的显式开关。未提供该开关时只执行默认精确流程。

### 3.3 对位验收

最终复测相对于录制第 0 帧参考的容差为：

- X（前后）：`abs(dx) <= 0.020 m`。
- Y（左右）：`abs(dy) <= 0.010 m`。
- Z：沿用现有固定偏移合同，`abs(dz) <= 0.030 m`。

底盘朝向使用录制书本长轴和当前书本长轴比较。第一版只做方向验收，不在同一次精对位中自动猜测大角度旋转。方向容差应由实现中的单一常量定义，并通过毫米误差预算导出；在参考点有效杠杆约 `0.174 m` 时，采用 `3°` 上限使旋转引入的位移约为 `9.1 mm`。

任一位置、方向、目标连续性或起始姿态条件不满足时，不得创建或调用回放器，不得发布 frame 0。

## 4. 参考数据合同

`ReplayPickReference` 从只保存 XYZ 扩展为至少包含：

- `asset_id`；
- `reference_frame_index`，固定为 `0`；
- 第 0 帧书本 `suction_point_base_m`；
- 第 0 帧书本 `long_axis_base`；
- 书本长边和短边尺寸；
- 用于生成参考的 HDF5 文件身份。

运行时必须验证 reference 的 `asset_id` 与实际 Pick 资产一致。真实资产合同测试必须读取 HDF5 并确认：

- 607 帧和时间戳严格递增；
- `target_qpos_arms`、`target_qpos_head`、`target_qpos_torso`、`target_base_vel` 形状正确且有限；
- 若 `target_base_vel` 中存在非零值，运行合同必须启用底盘发布并把该通道列入 required channels；
- 禁止再次出现“数据非零但配置静默跳过”的情况。

224×224 录像参考的内参缩放采用 OpenCV 像素中心公式：

```text
fx' = sx * fx
fy' = sy * fy
cx' = (cx + 0.5) * sx - 0.5
cy' = (cy + 0.5) * sy - 0.5
```

参考生成结果必须重新计算后写入项目配置；不在旧数值上手工补固定厘米数。

## 5. 目标选择与重关联

初始目标仍从当前有效书本中选择，但移动后的重关联必须同时满足：

- 与 odom/IMU 预测点的 X/Y 距离不超过单一配置阈值；
- 长短边尺寸与原目标一致到配置容差；
- 长轴方向差不超过配置阈值；
- 候选本身通过视觉置信度和 RGB-D 几何重建。

没有候选满足全部条件时视为目标丢失，不允许改选“最近的一本”继续抓取。

## 6. 第 0 帧姿态恢复

回放前读取实际反馈并恢复：

- 双臂 16 个关节；
- 头部 2 个关节；
- 升降柱 1 个关节，其中整条录制 torso 轨迹继续叠加本次固定 Z offset；
- 底盘通过视觉第 0 帧参考恢复 X/Y 和朝向；不能使用 HDF5 中恒为零、实际未采集的 `base_pose` 作为位姿证据；
- D01 必须处于 Pick 的初始空载状态。

双臂和头部从当前反馈到 frame 0 目标使用有界、连续的预置轨迹；不能直接把 frame 0 作为单帧绝对跳变命令。预置结束后读取反馈，与第 0 帧逐维比较，成功后才允许创建正式回放节点。

正式 607 帧数据保持原始顺序和时间间隔；预置轨迹不计入 DataReplay 帧数，也不修改 HDF5。

## 7. 完整回放和 D01 时序

正式回放必须启用 `target_base_vel`。底盘、双臂、头部和 torso 使用同一个 HDF5 frame index 与同一时间轴，不得把底盘轨迹提前合并成一个固定距离，也不得只按速度积分值发单次导航命令。

发布 frame 0 前等待控制器订阅建立。`frames_sent=607` 只作为发布计数；首帧准备由第 0 帧反馈验收证明，结束状态由关节反馈和 D01 holding 证明。

D01 的 `frame_index=300` 语义固定为：

```text
发布 frame 300 的机器人动作
→ 执行 right_suction_start
→ 获得命令确认
→ 按合同继续 frame 301...
```

如果吸附调用需要等待 holding，不得阻止 frame 300 本身到达控制器。是否在等待 holding 期间继续后续压靠帧必须由资产时序测试确定；第一版至少保证 frame 300 先发布，并保留事件后剩余回放。

## 8. 失败语义

这些不是比赛中的额外人工暂停，而是阻止错误动作进入正式回放的确定性软件条件。

- 对位或姿态复位失败：底盘置零，D01 不启动，零回放帧。
- 回放中普通故障：底盘立即置零并停止继续发布。
- D01 明确未吸住：发送 `right_suction_stop`。
- D01 已 holding 或状态未知：保持吸力，不自动释放可能已离桌的书；报告当前状态供后续任务处理。
- `KeyboardInterrupt` 与普通异常执行同一底盘停止逻辑，不能只在 `Exception` 分支清理。

失败后不自动把机械臂从中途姿态跳回 frame 0；下一次运行必须重新执行完整预置。

## 9. CLI 合同

- `--check` 默认关闭。
- `--check`、`--book-pick`、`--book-align` 和其他真实运动测试参数必须互斥；歧义组合在 ROS 初始化和任何动作前报错。
- 默认 `--book-pick` 不粗定位。
- 粗定位只由新的显式选项开启。
- 保留只对位、不回放的入口，用于部署后的第一阶段真机验证。

## 10. 测试与部署门槛

实现采用测试驱动，至少覆盖：

1. 真实 HDF5 的非零 base 通道不能被 disabled/skip。
2. 默认 Pick 不调用粗定位；显式开关才调用。
3. X 超过 20 mm、Y 超过 10 mm、Z 超过 30 mm或 yaw 超差时，回放零调用。
4. 目标书消失或重关联超距时拒绝换书。
5. 双臂、头部、torso 未到 frame 0 时不发布正式回放。
6. 正式回放保留 607 帧和原始 `target_base_vel`。
7. frame 300 发布发生在 D01 start 之前。
8. 已 holding/状态未知的失败不会自动关闭吸盘。
9. `--check` 与运动参数组合在初始化前失败。
10. OpenCV resize 内参中心公式的数值回归。
