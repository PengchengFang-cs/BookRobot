## 3. 混合起始对位参考

新资产的起始对位使用“X/Z 来自第 0 帧规则点，Y 来自真实接触点”的混合参考：

- X（前后）：在 frame 0 检测录制书本，使用既有 13 cm/10 cm 规则点的 X。回放内已经包含新的前进轨迹，不使用接触帧 X，也不把录制前进距离重复加入起始对位。
- Y（左右）：使用 frame 156–160 中吸盘与书面接触时的实际吸附点 Y。实现固定使用一张清楚的接触帧，并在标定叠加图中记录该帧编号和接触像素。
- Z（高度）：继续使用 frame 0 的 13 cm/10 cm 规则点 Z，运行时沿用现有 `observed_z - reference_z` 整轨 torso 偏移。
- 书本长轴、长边和短边：继续取 frame 0 的检测结果。

之所以允许接触帧 Y 直接回写起始参考，是因为该录制的底盘角速度为零且没有横移；录制中的前后平移会改变 X，但不会改变 base 坐标中的 Y。接触帧 X 不具备这个性质，因此明确不使用。

## 4. 接触点标定

标定只读新 HDF5，不发送机器人、机械臂或 D01 命令：

1. 在 frame 0 检测书本，计算 13 cm/10 cm 规则点、尺寸和长轴。
2. 在 frame 156–160 中选择吸盘与书面接触最清楚的一帧。
3. 使用 frame 0 作为无吸盘基线，从接触帧提取新出现的蓝色吸盘区域。
4. 在接触帧的书本可见区域中确定蓝色吸盘端部与书面相接的像素。
5. 将该像素射线投影到检测到的书本封面平面，仅取投影结果的 base Y。
6. 生成参考 JSON：`x=frame0_rule_x`、`y=contact_y`、`z=frame0_rule_z`。
7. 保存一张叠加图，同时标出书本轮廓、13/10 规则点、蓝色吸盘接触点、所选帧和最终混合 XYZ，供人工核对。

若单帧接触位置在 156–160 中有细小波动，取清晰接触帧附近结果的中位 Y；不对 X/Z 做同样替换。
