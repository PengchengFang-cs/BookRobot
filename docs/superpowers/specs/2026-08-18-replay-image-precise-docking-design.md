# DataReplay 图像基准两级精确对位设计

日期：2026-08-18

## 实测更正（后续实现以本节为准）

真实资产标定证明，不能把整块蓝色部件质心直接抄到早期深度，也不需要把录制右侧书本的局部 inset 复制给其他书。用户确认的接触位置是蓝色吸盘端部与书面相接的黄/蓝圈；对应早期书本 mask 的像素为 `(159, 180)`。该射线与录制书本封面平面相交后，固定 DataReplay 吸盘参考为：

```text
base_link = (0.7709968, -0.3608004, 0.7538117) m
```

五个录制状态样本的极差为 `(0.166, 0.191, 0.000) mm`。

录制右侧书本只用于确定“回放时吸盘中心在机器人坐标系中的固定位置”。抓五本书时，每本书仍使用当前视觉独立算出的 0.13/0.10 安全吸取点。最终公式固定为：

```text
residual_xyz = current_book.suction_point - replay_suction_reference
```

因此，下文任何“保存录制书局部 inset 并映射到当前书”的描述均由本节取代。

## 目标

Stage 1 抓书改为两级定位：实时视觉先确认书桌和目标书，并只把机器人带到约 `0.48 m` 的粗略工作范围；机器人停稳后，再读取本次 Pick DataReplay 的录制图像和深度，以录制时蓝色吸盘中心对应的真实接触点为基准计算精确 `X/Y/Z` 偏差。精确对位完成后才允许进入现有 DataReplay Pick。

`0.48 m` 只属于粗定位，不再作为 DataReplay 的最终 `base_link.x` 参考。现有“从书本下缘向内 0.13 m、从右边缘向左 0.10 m”的通用视觉点仍可用于发现书本和粗定位，但不能替代录制轨迹的实际吸盘接触点。

## 数据流

```text
离线、每个 DataReplay Pick 资产执行一次
  HDF5 第 300 帧 RGB + D01 事件
    → 分割新增的蓝色吸盘主体
    → 计算蓝色区域中心像素
    → 对应到多个早期无遮挡深度帧
    → 投影到各帧 base_link
    → 取中位数，生成资产专属 ReplayPickReference

在线、每次抓取
  当前 RGB-D 检测书桌和书
    → 锁定一个目标书
    → 只做约 0.48 m 工作范围的粗定位
    → 停稳后重新拍摄同一本书
    → 用 ReplayPickReference 计算精确 X/Y/Z 偏差
    → X/Y 交给底盘精确对位
    → Z 交给现有 DataReplay torso offset
    → 执行一次 Pick DataReplay
```

## 录制资产标定

新增纯数据模块 `replay_pick_reference.py`，不依赖 ROS，也不发送控制命令。它负责：

1. 从 HDF5 读取 `observation/image`、`observations/depth_head_rgbd`、`observations/qpos_head` 和 `observations/qpos_torso`。
2. 从 Pick 配置读取 D01 启动帧；当前资产为第 300 帧，不在算法中另外猜测接触时刻。
3. 将接触帧与早期无遮挡帧比较，在蓝色 HSV 范围内寻找接触帧新增的最大连通区域，以该区域质心作为吸盘中心。
4. 用第 0、10、20、40、80 帧该像素附近的有效深度中位数反投影；相机内参必须分别按宽、高缩放到 224×224，不能采用单一缩放比例。
5. 使用每一帧实际的 torso/head 状态调用现有 `camera_point_to_base(...)`。
6. 对五个 `base_link` 点逐轴取中位数，输出不可变的 `ReplayPickReference`，包含资产路径、接触帧、吸盘像素、三维参考点和样本数。

标定结果保存为项目中的小型 JSON 配置；不把 HDF5、图像、深度、模型或日志提交到 Git。运行期读取 JSON，不在每次比赛运行时重新扫描完整 HDF5。

## 两级导航

### 第一级：视觉粗定位

- 当前视觉先检测最多五本书，并锁定本轮目标。
- `APPROACH_DISTANCE_M=0.48` 只作为粗定位工作范围参数。
- 粗定位结束后必须重新拍摄；粗定位结果不直接触发 DataReplay。
- 目标身份不能在重新检测后按“离参考点最近”重新选择。根据粗移动的 odom `x/y/yaw` 将初始目标点变换到新的 `base_link`，再从候选中选择距离该预测点最近者，以保持同一本书。

### 第二级：DataReplay 精确对位

资产标定给出录制时实际吸盘接触点 `reference_contact_base_m`。当前帧仍利用整书 mask 和深度重建书本平面；把录制吸盘中心在书本局部长轴/短轴上的位置应用到当前书本，得到 `observed_contact_base_m`。

精确偏差定义为：

```text
residual = observed_contact_base_m - reference_contact_base_m
```

- `residual.x/y` 只进入底盘精确对位。
- `residual.z` 原样成为现有 `z_offset_m`，不乘 gain、不逐轮累加。
- 第二级移动后重新检测并报告最终残差；报告不再使用通用 0.13/0.10 点。
- Pick 入口只消费第二级计算得到的 `z_offset_m`。

为了把录制接触位置转移到当前不同尺寸或略有旋转的书本，资产标定同时保存接触点相对于录制书本长轴近端和机器人视角右边缘的局部米制 inset。`book_geometry.py` 新增按指定长/短轴 inset 计算点的纯函数；原有 0.13/0.10 默认行为保持不变，供现有视觉显示和粗定位继续使用。

## 代码边界

- `replay_pick_reference.py`：HDF5 图像/深度标定、吸盘蓝色中心提取、参考 JSON 读写和不可变数据类型。
- `book_geometry.py`：从已经重建的书本轴、边界和指定 inset 计算资产专属接触点。
- `book_alignment.py`：区分粗定位目标与 Replay 精确参考；计算精确 residual 和固定 Z offset。
- `mission.py`：编排“检测并锁书 → 粗定位 → 同书重关联 → 精确定位 → 最终测量 → Pick”。
- `book_navigation.py`：继续只执行 X/Y；不接收视觉 Z。
- `book_pick_replay.py`：继续只消费一个固定 Z offset 并修改内存中的 torso 轨迹，不修改 HDF5。
- `scripts/calibrate_replay_pick_reference.py`：只读资产并输出参考 JSON 和可视化叠加图，不发送任何机器人命令。

## 不在本次范围内

- 不修改机械臂轨迹、D01 吸盘实现或吸盘硬件。
- 不引入 MoveIt、碰撞模型或机械臂末端微调。
- 不恢复旧完整比赛 Pipeline。
- 不增加 SHA 校验、自动重试或与本功能无关的检查。
- 不把 GitHub 加入机器人部署链路。

## 测试与真机边界

纯测试覆盖：蓝色区域中心提取、非等比内参缩放、多早期帧三维中位数、书本局部接触点转移、同书 odom 重关联、粗定位与精确定位严格分离，以及 Pick 只接收精确阶段 Z offset。

离线资产测试必须重新得到约 `(0.7155, -0.3913, 0.7128) m` 的参考，并生成同时标注第 300 帧蓝色中心和早期投影点的叠加图。实现和离线验证不会让机器人运动。

任何后续真机测试仍须由用户再次明确允许并确认现场安全；第一次只执行粗定位并停下检查，第二次只执行精确对位并停下检查，确认两级坐标方向和距离后才单独运行 Pick。
