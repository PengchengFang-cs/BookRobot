# Stage 1 吸取点偏心分析

日期：2026-08-19（Asia/Shanghai）

状态：完成只读诊断；未修改运行算法，未再次发送机器人运动或 D01 命令。

## 现场结果

- Stage 1 回放到吸附阶段后已实际吸起 `FOLIO-02`；软件仍返回 `D01 event failed/faulted/stale`，因此不能据此声称 607 帧正常完成。
- 用户现场测量：Z 正确；实际吸附点相对书本真实中心，X 约偏 `50 mm`，Y 约偏 `10–20 mm`，肉眼方向为偏左。
- 本次抓取前最终视觉残差为 `dx=-8 mm`、`dy=-9 mm`、`dz=+16 mm`。Z 已作为固定偏移加入整条 torso 轨迹。

## 已确认的计算事实

### 1. 13 cm / 10 cm 点不是书本中心

当前算法从机器人视角近端沿长轴向内 `0.13 m`，再从右边缘沿短轴向左 `0.10 m`。它不是中心点算法。

录制参考书的几何为：

- 长边 `257.660 mm`
- 短边 `174.036 mm`
- 长轴约为 `base_link +X`

因此规则点相对该书几何中心的偏移为：

- 长轴：`130 - 257.660/2 = +1.170 mm`
- 从右向左的短轴：`100 - 174.036/2 = +12.982 mm`
- 换到 `base_link XY`：约 `(+1.74, +12.92) mm`

所以，即使视觉、导航和回放完全没有误差，`10 cm` 规则本身也会令该参考书的目标点位于中心左侧约 `13 mm`。这与现场 Y 偏 `10–20 mm` 同量级。

### 2. 本次最终残差会继续平移实际落点

回放开始时，当前书的规则点仍相对录制参考点残留 `(-8,-9) mm`。固定 DataReplay 轨迹不会消除该残差，因此实际吸盘相对当前书的目标位置会增加约 `(+8,+9) mm` 的反向偏移。

仅对录制参考书估算，规则偏心与本次残差合计约为：

- X：`1.7 + 8 = 9.7 mm`
- Y：`12.9 + 9 = 21.9 mm`

这足以解释现场 Y 偏左约 `1–2 cm`，但不能解释 X 约 `5 cm`。

### 3. 当前参考不是“真实吸盘接触点”标定

`config/stage1_pick_reference.json` 当前保存的是：在 HDF5 第 0 帧对录制书运行同一套 13/10 几何后得到的规则点：

```text
base_link=(0.9350956, -0.3075495, 0.7521206) m
```

它没有保存真实 D01 吸盘 TCP，也没有保存录制时真实接触点相对书本中心的偏移。运行时只是令“当前书规则点”对齐“录制书规则点”，随后原样回放录制动作。因此，录制动作本身若偏离书本中心，当前流程会忠实复现该偏移。

2026-08-18 曾尝试从第 300 帧蓝色部件估计接触点 `(159,180) px`，但该结果后来已作废。复核显示：把该蓝色部件像素按水平封面投影回第 0 帧，会得到书本范围之外的点；第 300 帧时底盘已经移动且蓝色可见中心不是书面 TCP 接触点。该旧结果不能作为真实接触标定。

### 4. DataReplay 内部 X 接近是开环速度回放

真实 Pick HDF5 在 frame 65–371 有 178 帧非零底盘线速度，角速度均为零。按录制时间戳积分：

- 到 frame 164：约前进 `350.8 mm`
- 到 D01 frame 300：净前进约 `348.9 mm`
- 全 607 帧：净约后退 `152.7 mm`

HDF5 的 `observations/base_pose` 在 607 帧中全部为零，当前 FPC 回放也只逐帧发布原始 `target_base_vel`，没有用 odom 闭环复现 frame 300 的真实底盘位置。

因此，若当前地面摩擦、轮胎回差或负载令这段约 `349 mm` 的实际位移相对录制改变约 14%，就会产生约 `50 mm` 的 X 接触误差。这是当前 X 偏差的重要候选根因；本次运行没有保存回放开始到 frame 300 的 odom，所以尚不能把它标成唯一根因。

## 已基本排除

- 当前 CameraInfo 的 `fx/fy/cx/cy` 与录制参考脚本使用的数值逐项完全一致。
- 录制第 0 帧和当前测试的头部俯仰均约为 `0.249617 rad`（`14.30°`）。
- 参考帧与当前目标在图像中的区域接近；按当前畸变参数复算，两处未去畸变造成的差分射线误差约 `0.2 mm`，不能解释 `50 mm`。
- 先前静止重复感知的 X/Y 波动约为 `1.5/1.0 mm`，也不能解释本次偏心。
- Z 在现场正确，说明 torso 固定偏移链路在本次实验中达到了预期方向和量级。

## 旧尺寸/朝向门禁的真实作用

旧代码曾要求当前书与录制书满足长短边差不超过 `50 mm`、长轴角差不超过 `3°`，否则不运行。该逻辑后来按用户要求删除。

它只是候选拒绝门，不参与 13/10 点计算，也不能校准真实吸盘接触点。删除它不会直接改变同一本书的坐标；但不同尺寸书仍使用固定绝对 `13 cm/10 cm` 后，规则点相对各自中心的位置必然不同。后续应记录尺寸和规则点相对中心的偏移作为诊断数据，不需要恢复运行门禁。

## 根因排序

1. **已确认：目标定义不等于中心。** `10 cm` 规则直接解释约 `13 mm` 的参考书 Y 偏心；不同尺寸书还会产生不同的 X/Y 中心偏移。
2. **已确认：当前没有真实接触点/TCP 标定。** 第 0 帧只标了视觉规则点，录制物理落点偏差会被完整继承。
3. **高概率：回放内约 349 mm 的 X 运动是开环速度复现。** 约 14% 的位移差即可解释 50 mm；需要下一次记录 odom 才能定量确认。
4. **已确认的小贡献：本次最终残差。** 它会贡献约 8 mm X、9 mm 左偏，但不是 50 mm X 的主因。
5. **低概率：相机内参、头角或短期视觉噪声。** 当前证据与 50 mm 量级不符。

## 下一次最小验证

不增加运行门禁，也不立即改回放轨迹。下一次先保存测量证据：

1. 将书平放，输出同一 capture 的书本几何中心、13/10 点、长短轴和长短边；直接得到“规则点相对中心”的 X/Y。
2. 回放期间只增加记录：frame 0、frame 300、frame 606 的 odom；不改变动作和停止条件。用 frame 300 实际位移对比 `348.9 mm` 命令积分。
3. 在书面中心贴一个可见小标记，抓取后由图像或人工测量给出吸盘相对中心的有方向 X/Y，不只记录绝对值。
4. 若任务目标确定为几何中心，应把视觉目标模式改为中心，而不是继续称 13/10 点为中心；同时仍需用一次实测求出录制物理接触点相对录制书中心的固定偏移。
5. 若 X 偏差主要来自 frame 300 实际底盘位移，则把 DataReplay 内底盘段改为 odom 目标复现或经实测校准的位移轨迹；不要用相机外参或 13/10 常量掩盖底盘开环误差。
